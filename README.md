# 拼图工具 · Collage Tool

一个**纯本地、免费、无需联网**的网页拼图工具，主打**规整网格模板**。
用来替代 WPS 拼图，解决它慢、收费、模板少的问题。

🌐 **在线使用**：https://pamelaaaaa1218.github.io/collage-tool/

## ✨ 特点

- 🔒 **纯本地运行**：图片只在你电脑里处理，不上传任何服务器
- 🆓 **完全免费**：无水印、无次数限制
- 📐 **模板丰富**：主打规整网格 + 固定宫格（四宫格 / 九宫格…）
- 🎨 **高度可调**：间距、圆角、边距、背景、画布比例全部可调
- 💾 **一键导出**：PNG / JPG，支持高清 / 超清
- 📦 **指定文件大小**：可设目标体积（如 ≤2MB），导出自动压到目标内，省去二次压缩

## 📦 模板一览

| 分组 | 模板 |
|---|---|
| **新增：原图自定义宫格**（不裁剪） | 2列×2行、2列×3行、3列×2行、2列×4行、4列×2行；也可自定义 1–8 列 / 1–8 行 |
| **规整网格**（行数随图片自动增加） | 自适应、1~6 列 |
| **固定宫格**（格子数固定，最规整） | 四宫格 2×2、六宫格 3×2、竖六格 2×3、九宫格 3×3、十二格 4×3、十六格 4×4 |
| **长图拼接**（不裁剪） | 竖向长图、横向长图 |
| **经典组合** | 左1右2、左2右1、上1下2、上2下1、左1右3、上1下3、左1右4、上1下4、中大四角 |

## 🎛 可调参数

- **图片填充**：裁剪填满（规整）/ 完整显示（留白）
- **画布比例**：自适应 / 1:1 / 4:3 / 3:4 / 3:2 / 2:3 / 16:9 / 9:16 / 4:5 / 5:4 / 2:1 / 1:2
- **间距 / 外边距 / 圆角**：滑块实时调整
- **背景色**：预设色块 + 自定义 + 透明（仅 PNG）
- **导出尺寸**：标准 1200 / 高清 2000 / 超清 3000 px
- **导出文件大小**：不限制 / ≤500K / ≤1M / ≤2M / ≤5M / 自定义（KB·MB）。设了目标体积后按 JPG 自动压到目标内（先降质量、不够再降尺寸），导出后提示实际大小

## 🚀 使用方法

https://pamelaaaaa1218.github.io/collage-tool/，用浏览器打开即可（推荐 Chrome / Edge / Safari）。

操作三步：
1. 拖入 / 点击上传图片（支持多选，可拖到页面任意位置）
2. 右侧选模板 → 调参数
3. 点击导出（PNG 高清 / JPG 更小）

左侧缩略图可**拖拽排序**、单张删除。

### 新增：原图自定义宫格

右侧顶部选择“新增 · 原图自定义宫格（不裁剪）”，再选排列方式，或直接填写列数（横向）和行数（纵向）。

- 每张照片等比缩放，完整显示原图四边，画布高度随照片比例变化。
- 各列等宽，每行高度由该行最高的照片决定；横竖图混排时，较矮的照片上下留白。
- 间距、外边距、背景色、导出尺寸、PNG / JPG 和目标体积压缩均可继续使用。
- 此模式不套用旧模板的画布比例、裁剪和圆角；切回旧模板时，这些设置仍保留。
- 照片不足时保留空位；超过宫格容量时只拼前面的照片，并明确提示未加入数量，可增加行列数或拖拽排序。
- “原图”指完整内容与原始比例；导出像素尺寸仍由标准 / 高清 / 超清设置及原有画布上限决定。

原有规整网格、固定宫格、横向 / 竖向长图和经典组合均保留。
